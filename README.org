* SYFI

[SY]stem of [FI]le-system systems

A comprehensive, discoverable entry point for Common Lisp
pathname, directory and filesystem related systems.

* Motivation

Pathname / filesystem functionality in Common Lisp is spread across the
ANSI standard, UIOP, cl-fad, pathname-utils, filesystem-utils,
file-finder, path-string, and many smaller libraries.

New (and old) wizards have no single place to look.

SYFI gathers everything into one kitchen-sink package,
and soon, into discoverable subpackages.

- syfi
  Everything and the kitchen-sink

- syfi/pathname
  Pure pathname object tools

- syfi/probe
  Read-only existence/type queries

All other categories are to follow the same conduit pattern.

As the remaining subpackages are filled in
further collisions will be handled the same way

* Design principles

- Zero renaming – original symbol names are preserved.
- UIOP preferred on name collisions.
- Uses conduit packages (via org.tfeb.conduit-packages) for re-export and inclusion exclusion
- Kitchen-sink first – (use-package :syfi) gives the complete surface.
- Categorical subpackages – smaller, intention-revealing views that can be used independently.
- osicat excluded by design.

* Quick start

(asdf:load-system :metarepl.systems.syfi)

(use-package :syfi)

;; or the smaller views
(use-package :syfi/pathname)
(use-package :syfi/probe)

* Ontology of categories

- pathname
  Pure pathname objects (no I/O).
  Construction, predicates, components, normalisation,
  absolute/relative, logical/physical, wildcards.

- namestring
  String ↔ pathname and pure string path manipulation.
  Native/Unix/DOS namestrings, join, split, dirname/basename/extname.

- components
  Fine-grained component access and reconstruction.
  host/device/directory/name/type/version, plists, split-name-type.

- probe
  Existence and type queries (read-only).
  probe-file*, file-exists-p, directory-p, truename*, basic attributes.

- directory
  Listing and walking.
  directory*, directory-files, walk-directory, collect-sub*directories.

- mutate
  Creating, deleting, renaming, copying.
  ensure-directories-exist, delete-directory-tree, copy-file*, rename\ldots

- logical
  Logical pathnames.
  logical-pathname, translations, translate-logical-pathname.

- cwd
  Current working directory and process context.
  getcwd, with-current-directory, user-homedir-pathname.

- wild
  Wildcard utilities.
  *wild*, *wild-file*, *wild-directory*, wilden, pathname-match-p.

- temp
  Temporary files and staging.
  temporary-file helpers, tmpize-pathname, tmpdir.

- attributes
  Rich file metadata.
  size, extended timestamps, permissions\ldots

- search
  High-level search and discovery.
  file-finder / finder / finder*.

- config
  User/application configuration and data locations.
  nfiles, path-parse of $PATH, XDG-style resolution.

- special
  Niche / legacy helpers.
  illogical-pathnames, certain cl-ana utilities, etc.

* Systems re-exported

uiop, cl-fad, pathname-utils, filesystem-utils, file-finder,
path-string, illogical-pathnames, com.gigamonkeys.pathnames,
temporary-file, tmpdir, file-notify, file-attributes, trivial-file-size,
